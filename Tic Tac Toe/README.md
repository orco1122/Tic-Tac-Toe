# Python Tic Tac Toe

A classic, interactive Tic Tac Toe game built using Python. This project is a simple implementation of the traditional grid-based game where two players compete to get three of their marks in a row.

## 🚀 Features
* **Two-player mode:** Play locally with a friend.
* **Input Validation:** Prevents players from choosing an already occupied spot or invalid characters.
* **Win/Tie Detection:** Automatically detects when a player wins or if the game ends in a draw.
* **Clean Interface:** Uses a simple command-line interface (CLI) for gameplay.

## 🛠️ Prerequisites
Before you begin, ensure you have [Python](https://www.python.org/downloads/) installed on your machine (version 3.6 or higher).
