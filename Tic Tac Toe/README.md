# Python Tic Tac Toe

Developed a Python-based logic for Tic-Tac-Toe, emphasizing **Object-Oriented Programming (OOP)** principles and efficient **Data Structures**. 
Implementation focuses on clean code architecture and an intuitive user experience.
## 🚀 Features
* **Two-player mode:** Play locally with a friend.
* **Input Validation:** Prevents players from choosing an already occupied spot or invalid characters.
* **Win/Tie Detection:** Automatically detects when a player wins or if the game ends in a draw.
* **Clean Interface:** Uses a simple command-line interface (CLI) for gameplay.
**Key Features:**
**Object-Oriented Design:** The game is built using a class-based structure for better maintainability and encapsulation.
**Dynamic Logic:** Includes algorithms for win detection (rows, columns, diagonals) and handling draw scenarios.
**User Experience**: Clean command-line interface with input validation to ensure a seamless flow.

**Technologies Used:**
**Language:** Python
**Concepts:** OOP, Matrix-based Data Structures, Input Validatio
